# रोजचा जमा खर्च अहवाल

## Personal Finance Tracker

रोजचे उत्पन्न, खर्च, खाते शिल्लक आणि मासिक बजेट व्यवस्थापित करण्यासाठी तयार केलेले Personal Finance Tracker App.

## मुख्य Features

- 💰 जमा (Income) नोंद
- 💸 खर्च (Expense) नोंद
- 📊 एकूण जमा आणि खर्च
- 💳 Cash / Bank / UPI खाते व्यवस्थापन
- 📋 व्यवहारांची संपूर्ण यादी
- 📅 तारीख आणि महिन्यानुसार व्यवहार
- 🎯 Monthly Budget
- 📈 Budget वापराचे Percentage
- 🔔 खर्च नोंदवण्यासाठी Reminder
- 📊 Reports
- ⚙️ Settings
- 🔐 Login ID आणि Password
- 📱 Mobile Friendly Design
- 📲 PWA App Installation
- 🌐 Offline Support
- 💾 Local Storage मध्ये Data Save
